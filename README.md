# Compêndio D&D 2024

O site possui três áreas principais: **Personagem**, **Itens** e **Monstros**. A área Itens apresenta cartões pesquisáveis e uma ficha de detalhes ao selecionar um registro.

## Detalhes da área Itens

- Os 196 equipamentos mundanos possuem preço, peso ou capacidade, descrição de uso e, conforme a categoria, dano, propriedades, maestria, Classe de Armadura, requisito de Força, penalidade de Furtividade, atributo e informações de ferramentas/montarias.
- As abreviações de moedas são exibidas em português (PC, PP, PE, PO e PL); pesos são mostrados em libras (lb).
- Os 258 itens mágicos do SRD 5.2.1 carregam a descrição integral e propriedades detalhadas sob demanda, ao abrir a ficha do item. Esse recurso exige internet e utiliza a API pública do DM's Toolkit. O texto integral retornado pela API está em inglês; raridade, sintonia, preço estimado e peso disponível são apresentados separadamente.
- Valores em ouro para itens mágicos são estimativas orientativas por raridade, não preços fixos de loja. O SRD não especifica o peso de todos os itens mágicos.
- Os 71 registros adicionais do índice do Livro do Mestre 2024 contêm apenas nomes públicos de referência. As regras completas, pesos e preços não são preenchidos quando não há dados abertos suficientes.
- Os botões de impressão foram removidos. A interface de itens não exibe o campo “Fonte:”.

## Arquivos

`index.html` carrega `especies.js`, `classes.js`, `antecedentes.js`, `spells.js`, `itens.js` e `monsters.js`.

O catálogo de monstros utiliza a base SRD 5.2.1 por CDN e requer internet. As descrições comerciais não abertas dos livros oficiais não estão incluídas.
