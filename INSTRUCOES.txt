CORREÇÃO DA ÁREA DE MAPAS — ANIMALYSSON RPG

Como aplicar:
1. Faça uma cópia de segurança do seu repositório.
2. Extraia o conteúdo deste ZIP diretamente na raiz do repositório, mantendo as pastas.
3. Quando solicitado, substitua o index.html existente.
4. Confirme que o novo arquivo css/mapa-fix-canvas.css foi adicionado.
5. Envie/commit as alterações para a branch main e aguarde o GitHub Pages publicar.
6. Abra o site e atualize com Ctrl+F5 (ou limpe o cache do navegador).

O ZIP contém somente:
- index.html (igual ao atual, com a inclusão do CSS de correção)
- css/mapa-fix-canvas.css (novo arquivo)

Nenhum módulo JavaScript, mapa, personagem ou dado salvo foi substituído.
A correção restaura uma altura útil para o contêiner do mapa e para o canvas,
inclusive em telas menores.
